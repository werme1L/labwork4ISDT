### 1.1 Цели работы

Научиться создавать и запускать модульные тесты (Unit-тесты) для проверки корректности работы программы.

### 1.2 Задачи работы

1.	Разработать программу-калькулятор на Python.
2.	Изучить возможности модуля unittest.
3.	Написать тесты для проверки основных арифметических операций.
4.	Запустить тесты и проанализировать полученные результаты.

### 2. Описание тестируемого продукта

В качестве тестируемого продукта была разработана программа-калькулятор на языке Python.

Программа выполняет четыре основные арифметические операции: 
- сложение двух чисел 
- вычитание одного числа из другого
- умножение двух чисел
- деление одного числа на другое.

Каждая арифметическая операция реализована в виде отдельной функции. 

### 3. Область тестирования

- функция сложения add();
- функция вычитания subtract();
- функция умножения multiply();
- функция деления divide();
- обработка деления на ноль.

### 4. Стратегия тестирования

- Использован модуль unittest из стандартной библиотеки Python.
- Для каждой проверяемой ситуации создан отдельный тест.
- Использован assertEqual() для сравнения ожидаемого и фактического результата.
- Использован assertRaises() для проверки возникновения исключения при делении на ноль.
- Запущены все тесты и проверены их результаты



### 5. Критерии приёмки

Программа считается успешно протестированной при выполнении следующих условий:

1. Все 9 разработанных тестов проходят успешно.
2. Результаты выполнения арифметических операций соответствуют ожидаемым значениям.
3. При попытке деления на ноль возникает исключение `ZeroDivisionError`.
4. Во время выполнения тестов не возникает неожиданных ошибок.

### 6. Ожидаемые результаты

В результате тестирования ожидается успешное прохождение всех 9 разработанных модульных тестов.

Предполагается, что все арифметические функции будут возвращать корректные результаты для проверяемых значений, а при делении на ноль будет возникать исключение `ZeroDivisionError`.

При успешном выполнении всех проверок программа должна вывести сообщение `OK`.
